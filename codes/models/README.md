# NanoDet model

`object_detection_nanodet_2022nov.onnx` comes from the [OpenCV Zoo NanoDet model directory](https://github.com/opencv/opencv_zoo/tree/main/models/object_detection_nanodet). It is used here for the COCO `person` class.
